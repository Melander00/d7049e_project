
## Subsystems and Timing

| Subsystem       | What it means for us             | Timing              |
| --------------- | -------------------------------- | ------------------- |
| InputSystem     | maps input to movement/action    | every frame         |
| MovementSystem  | write intended movement/velocity | fixed 60 Hz         |
| AgentSystem     | simple enemy behavior            | fixed 60 Hz for now |
| PhysicsSystem   | Bullet step(internal timestep)                     | every frame         |
| CollisionSystem | collision responses/messages     | fixed 60 Hz         |
| CameraSystem    | follow physics/player state      | fixed 60 Hz         |
| AnimationSystem | visual animation only            | every frame         |
| RenderSystem    | draw world/UI                    | every frame         |
| Profiling/Debug | timings, FPS, debug draw         | every frame         |



## Core choice

Single-threaded now, multicore-ready later

Benefit: simplest to debug and easiest to finish.

Main risk: performance may become a bottleneck at high entity counts.

Why it fits: our scope is still MVP-level and we want to focus more on critical system design rather than force parallelism early.

## Suggested Game Loop

```java
init();
float accumulator = 0f;
float fixedDt = 1f / 60f;

while (true) {
    float frameDt = Gdx.graphics.getDeltaTime();
    frameDt = clamp(frameDt, 0f, 0.25f);

    pollInput();                // raw OS / LibGDX input
    if (quitRequested()) break; // loop-control, outside ECS
    boolean paused = isPaused(); // loop-control, outside ECS

    debug.beginFrame();

    inputSystem.update(frameDt); // writes axisX, axisY, action1, action2 into InputComponent

    if (!paused) {
        accumulator += frameDt;
        while (accumulator >= fixedDt) {
            movementSystem.update(fixedDt);
            agentSystem.update(fixedDt);
            collisionSystem.update(fixedDt);
            cameraSystem.update(fixedDt);
            scriptSystem.update(fixedDt);
            accumulator -= fixedDt;
        }
        physicsSystem.update(frameDt); // raw frameDt — Bullet handles fixed stepping internally
        animationSystem.update(frameDt);
    }

    renderSystem.update(frameDt);
    debug.render();
    debug.endFrame();
}
shutdown();
